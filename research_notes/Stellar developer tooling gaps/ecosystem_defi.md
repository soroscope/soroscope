# Stellar ecosystem-level developer tools: DeFi, assets, anchors, compliance, analytics (as of 2026-10-08)

Method note: star counts and last-push dates come from the GitHub REST API (search and repo endpoints, queried 2026-10-08), so each repo URL below is the source for its own numbers. Some searches ran through a summarizing fetch tool and a few queries returned zero or noisy results, so absence of a repo in my results is NOT proof it does not exist. "Stale" = no push in more than 12 months (before 2025-10-08). Not covered or unverified: Lumenscan, Steexp, Stellarchain, Aquarius SDK, Axelar on Stellar, DefiLlama Stellar, SCF project lists (see Gaps).

## Which developer-facing utilities are missing around DeFi, assets, anchors, compliance and analytics?

### Takeaway
Core protocol repos (Soroswap, Blend, Phoenix, Reflector, anchor tooling) are well maintained, but most real developer utilities around them are thin or absent. The clearest gaps are a mature SEP-1 stellar.toml linter, a SAC/SEP-41 inspector, a trustline auditor, claimable-balance and bulk-operation builders, and an end-to-end tax/accounting tool. Many "gap" repos exist only as brand-new 0 to 6 star projects, so they are unproven.

### Inferences
- Missing/weak, ranked by evidence: (1) a rigorous SEP-1 stellar.toml linter (existing ones are 0 to 6 stars, or stale; none verified to check CURRENCIES vs on-chain asset, SEP-10 signing key, ORG_URL reachability, or `[[CURRENCIES]]` asset-code/issuer consistency); (2) SAC vs custom SEP-41 inspector/diffing (only soroban-guard, 6 stars, brand new); (3) trustline auditor (only 0 to 4 star apps, no CLI/library that audits an account's trustlines for unauthorized/frozen/clawback/AUTH flags); (4) claimable-balance and bulk-operation builders (official utils repo archived, batch tools tiny); (5) Stellar tax/cost-basis engine (only an unmaintained SDF-adjacent exporter); (6) compliance primitives (all new, 0 stars).
- Archived/stale official pieces create openings: django-polaris archived (Python anchor server), stellar-expert/claimable-balance-utils archived, operations-notifier stale since 2020, Stellar Quest repos stale since 2022, Blend v1 and liquidation bot stale.
- Most feasible in TypeScript: stellar.toml linter (pure fetch+parse+Horizon/RPC cross-checks), trustline/asset-flag auditor, SAC/SEP-41 inspector (RPC simulate `name/symbol/decimals/balance` plus spec diff), bulk operation / claimable-balance builder with 100-op batching and fee-bump, tax-export from Horizon/RPC to CSV (Koinly/CoinTracking format). Harder: oracle aggregator, LP analytics (need indexer infrastructure).
- Stars signal low adoption across the board; even official Soroswap SDK has 2 stars, so "obscure" is the norm for Stellar DeFi dev tools.
